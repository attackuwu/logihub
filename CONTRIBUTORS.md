## Как попасть в список

1. Откройте [Pull Request](CONTRIBUTING.md) с полезным изменением
2. Дождитесь ревью и слияния
3. Мейнтейнер добавит вас в таблицу выше

**Учитываются все виды вклада:**

| Тип вклада | Пример |
|------------|--------|
| Поддержка нового устройства | Добавление PID, тестирование HID++ команд |
| Исправление ошибок | Устранение падений, ошибок доступа, взаимных блокировок |
| Улучшение интерфейса | Новые элементы интерфейса, анимации, темы |
| Документация | README, CONTRIBUTING, переводы wiki |
| Пакетирование | AUR, Flatpak, COPR, Homebrew |
| Тестирование | Проверка на дистрибутивах, отличных от CachyOS, и других мышах |
| Предложения | Качественно оформленные Issue с идеями по реализации |
