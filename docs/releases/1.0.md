## О релизе

**LogiHub for Linux v1.0** — первая стабильная версия открытого приложения для управления RGB-подсветкой мышей Logitech LIGHTSYNC под Linux.

Написан на чистом **C17 + GTK4**, взаимодействует с устройством напрямую через **протокол HID++** (hidraw).  
Без Wine. Без Electron. Без проприетарного G HUB.

---

## Что нового

### Интерфейс

- Современное окно GTK4 в тёмной теме с CSS-стилизацией
- **HSV-цветовое колесо** — кольцо оттенка + квадрат насыщенности и яркости
- Компактная карточка устройства с иконкой и индикатором состояния
- Плавные переходы и отзывчивое управление

### Эффекты подсветки

| Режим | Описание |
|-------|----------|
| **Статичный** | Фиксированный цвет (любой оттенок, насыщенность и яркость) |
| **Дыхание** | Плавное затухание и разгорание выбранным цветом |
| **Перелив цветов** | Циклическая смена всех цветов спектра |
| **Волна** | Бегущая волна по всей длине подсветки с выбором направления |

### Элементы управления

- Ползунок яркости (0–100%)
- Ползунок скорости анимации
- Переключатель направления волны: вправо / влево
- Кнопка «Выключить подсветку»
- Кнопка «Переподключиться» для восстановления связи с устройством

### Системная интеграция

- **Автоматическая установка udev-правил** через `pkexec` при первом запуске — без необходимости ручной настройки udev
- Скрипт `install-udev.sh` для ручной установки правил
- Скрипт `package-release.sh` для сборки релизных архивов

## Поддерживаемые устройства

**Полная поддержка гарантируется только для Logitech G102 LIGHTSYNC.**  
Остальные модели официально не тестировались, но могут работать.

| Модель | USB ID | Статус |
|--------|:------:|:------:|
| **Logitech G102 LIGHTSYNC** | `046d:c092` | Полная поддержка |
| Logitech G102 (старая ревизия) | `046d:c084` | Вероятно совместима |
| Logitech G203 LIGHTSYNC | `046d:c08b` | Вероятно совместима |

Инструкция по добавлению нового устройства: [CONTRIBUTING.md](https://github.com/attackuwu/logihub/blob/main/CONTRIBUTING.md) — процесс обычно занимает 10–15 минут.

## Поддержка дистрибутивов

| Дистрибутив | Статус |
|-------------|:------:|
| **CachyOS** | Основная платформа — полная поддержка |
| Arch Linux | Ожидается работа (тот же набор пакетов) |
| Fedora 39+ | Требуется GTK4 ≥ 4.10 |
| Ubuntu 24.04+ | Требуется GTK4 ≥ 4.10 |
| Прочие | Совместимость не гарантирована — тестирование приветствуется |

## Скачать

### Готовый бинарник

| Файл | Платформа |
|------|:--------:|
| [`logihub-1.0-linux-x86_64.tar.gz`](https://github.com/attackuwu/logihub/releases/download/1.0/logihub-1.0-linux-x86_64.tar.gz) | Linux x86_64 |

**Установка:**

```bash
tar xzf logihub-1.0-linux-x86_64.tar.gz
cd logihub-1.0
./logihub
```

При первом запуске подтвердите установку udev-правил в диалоговом окне `pkexec`.  
Если доступ к мыши не появился после установки — **переподключите USB-кабель или приёмник**.

### Сборка из исходников

```bash
git clone https://github.com/attackuwu/logihub.git
cd logihub
meson setup build --buildtype=release
meson compile -C build
./build/logihub
```

**Зависимости:** `meson`, `ninja`, `gcc` / `clang`, `pkg-config`, `gtk4 ≥ 4.10`

## Структура исходного кода

```
logihub/
├── src/
│   ├── main.c           # Точка входа, интерфейс GTK4, HSV-виджет
│   ├── device.c         # Протокол HID++, hidraw, отправка команд
│   ├── device.h         # Типы данных: LightSettings, DeviceResult и др.
│   ├── udev_install.c   # Установка udev-правил через pkexec
│   └── udev_install.h   # Объявления функций udev
├── udev/
│   └── 99-logitech-hub.rules
├── meson.build          # Конфигурация системы сборки Meson
├── package-release.sh   # Скрипт сборки релизного архива
├── install-udev.sh      # Скрипт ручной установки udev
├── README.md
├── CONTRIBUTING.md
├── CONTRIBUTORS.md
└── LICENSE              # GNU GPL v2.0
```

## Известные ограничения версии 1.0

- Поддерживаемые USB PID: только `c092`, `c084`, `c08b`
- Готовый бинарник: только Linux x86_64 (собран на CachyOS)
- Язык интерфейса: русский
- Функционал: только RGB-подсветка — без профилей, макросов, DPI и настройки частоты опроса
- Требуется GTK4 ≥ 4.10 — может отсутствовать в старых LTS-дистрибутивах
